# Portfolio Reddad Chaouay

Un portfolio moderne et professionnel présentant le parcours et les projets de Reddad Chaouay, étudiant en Ingénierie Informatique (IA & Data) à l'EMSI.

## 🚀 Fonctionnalités

- **Design moderne et responsive** : Interface élégante qui s'adapte à tous les écrans
- **Navigation fluide** : Menu de navigation fixe avec défilement smooth
- **Animations interactives** : Effets de scroll, transitions et animations subtiles
- **Formulaire de contact** : Interface fonctionnelle pour envoyer des messages directs
- **Timeline éducation** : Présentation visuelle du parcours académique (EMSI, Diplôme de langues, Baccalauréat)
- **Galerie d'expériences & projets** : PFA Startis Car avec RAG, Analytics SportsTech, etc.
- **Compétences détaillées** : Langues (5 langues) et technologies (Data Science, IA, Web, Bases de données)
- **Certifications** : Showcase des certifications professionnelles (Google, Meta, EPFL, etc.)

## 📁 Structure du projet
